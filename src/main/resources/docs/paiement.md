# Paiement

## Moyens de paiement

Boutique Bil accepte la carte bancaire (Visa, Mastercard, CB), PayPal et Apple Pay.
Les chèques et les virements ne sont pas acceptés.

## Paiement en plusieurs fois

Le paiement en 3 fois sans frais est proposé par carte bancaire, dès 100 € d'achat.

## Moment du débit

Ta carte est débitée au moment de l'expédition, pas au moment de la commande.
À la commande, la banque peut afficher une pré-autorisation du même montant.
Ce n'est pas un second débit : elle disparaît sous 7 jours.

## Codes promo

Un seul code promo par commande.
Le code BIENVENUE10 donne 10 % de réduction sur la première commande.
Un code se saisit avant le paiement : il ne peut pas être ajouté après.

## Factures

La facture est disponible dans « Mon compte », puis « Mes commandes », après l'expédition.
